# Come get comfortable: Maple introduction

Selected ElevenLabs Voice Design speech; original fictional adult voice, no real-person clone. The MP4 is an offline PNGtuber render, with an AI/synthetic-voice label visible throughout.

- Video: 960 × 720, 24 fps, 259.375 seconds, H.264/yuv420p + mono AAC
- Source speech: selected Generation 1 MP3; no pitch shift or time stretch
- Captions: 77 approximate cues, in captions.srt and timing.json
- Script: script.txt and structured script.json
- Assets: shared four-state artwork in ../../assets/aligned/

Reproduction commands are in the root README. Generated outputs go into this example's build/ directory. The timing data uses static gain and silence padding for its PCM master. Caption boundaries are waveform-grounded estimates, not verified word alignment. Exact spoken delivery and performance were not independently audited by ear.

See ../../voice/README.md for account portability and ../../RIGHTS.md before further reuse.
